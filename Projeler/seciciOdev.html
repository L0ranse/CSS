Seçici Ödev

Bu ödevde, CSS seçicilerini kullanarak farklı HTML öğelerine stil uygulayacağız. Aşağıda, çeşitli CSS seçicilerini kullanarak oluşturulmuş bir örnek bulunmaktadır.

CSS Seçicileri

  • Element Seçici: Belirli bir HTML öğesini seçer. Örneğin, p seçici tüm paragraf öğelerini seçer.
  • ID Seçici: Belirli bir ID'ye sahip öğeyi seçer. Örneğin, #myId seçici ID'si "myId" olan öğeyi seçer.
  • Sınıf Seçici: Belirli bir sınıfa sahip öğeleri seçer. Örneğin, .myClass seçici sınıfı "myClass" olan tüm öğeleri seçer.
  • Grup Seçici: Birden fazla öğeyi aynı anda seçer. Örneğin, h1, h2, h3 seçici tüm başlık öğelerini seçer.
  • Aile Seçici: Belirli bir öğenin çocuklarını veya torunlarını seçer. Örneğin, div p seçici tüm div içindeki paragraf öğelerini seçer.
