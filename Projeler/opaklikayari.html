Opaklık Ayarı

Bu sayfada, HTML ve CSS kullanarak opaklık ayarını nasıl yapabileceğinizi göstermek istiyorum.

Opaklık, bir öğenin ne kadar saydam olduğunu belirler. Opaklık değeri 0 ile 1 arasında olabilir. 0 tamamen saydam, 1 ise tamamen opaktır.

Örneğin, aşağıdaki CSS kodu bir div öğesinin opaklığını %50 yapar:

                .my-div {
                    opacity: 0.5;
                }

Bu kodu kullanarak, .my-div sınıfına sahip bir div öğesi yarı saydam olacaktır.

Bu div öğesi opaklık ayarı uygulanmış bir örnektir.
