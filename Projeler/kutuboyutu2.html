Kutu Boyutu

Kutu boyutlarını ayarlamak

Kutu boyutlarını ayarlamak için width ve height özellikleri kullanılır.

width özelliği, kutunun genişliğini belirler. height özelliği ise kutunun yüksekliğini belirler.

Örneğin, aşağıdaki CSS kodu, bir kutunun genişliğini 200 piksel ve yüksekliğini 100 piksel olarak ayarlar:

            #kutu {
                width: 200px; /* Kutu genişliğini 200 piksel olarak ayarlıyoruz */
                height: 100px; /* Kutu yüksekliğini 100 piksel olarak ayarlıyoruz */
            }

Bu kodu kullanarak, bir kutunun boyutlarını istediğiniz gibi ayarlayabilirsiniz. Ayrıca, width ve height özelliklerine yüzde (%) değerleri de verebilirsiniz. Bu durumda, kutunun boyutları, içeren öğenin boyutlarına göre ayarlanır.

Örneğin, aşağıdaki CSS kodu, bir kutunun genişliğini içeren öğenin genişliğinin %50'si ve yüksekliğini içeren öğenin yüksekliğinin %30'u olarak ayarlar:

            #kutu {
                width: 50%; /* Kutu genişliğini içeren öğenin genişliğinin %50'si olarak ayarlıyoruz */
                height: 30%; /* Kutu yüksekliğini içeren öğenin yüksekliğinin %30'u olarak ayarlıyoruz */
            }

Bu kodu kullanarak, bir kutunun boyutlarını içeren öğenin boyutlarına göre ayarlayabilirsiniz. Bu, responsive (duyarlı) tasarımlar oluşturmak için özellikle faydalıdır.
